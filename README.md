# Simple Interest Calculator

This Git and GitHub project provides a Bash calculator that computes simple
interest from the principal amount, annual rate of interest, and time period.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

```
Inputs:
   Principal (P): the initial principal amount
   Rate (R): the annual rate of interest as a percentage
   Time (T): the time period in years

Output:
   The calculator displays the calculated simple interest result.
```
